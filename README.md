# Gestion des notes d'étudiants en C++

Application console développée en C++ avec Visual Studio Community dans le cadre de la programmation orientée objet (POO).

**Fonctionnalités :**
- Génération automatique d'identifiants uniques.
- Gestion des notes avec un tableau dynamique.
- Validation des notes entre 0 et 20.
- Calcul et affichage de la moyenne.
- Suivi du nombre d'étudiants existants.
- Gestion de la mémoire avec `new[]` et `delete[]`.

**Concepts utilisés :** classes, encapsulation, constructeurs, destructeurs, attributs `static`, méthodes `const` et allocation dynamique de mémoire.
